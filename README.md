# University Choice Platform

A web platform designed to help users explore universities, discover academic programs, and compare university information.

## Features

- Explore university information
- Browse departments and academic programs
- View university rankings and locations
- Discover university campuses

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS

## Getting Started

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Status

This project is under development. More features and improvements will be added over time.
